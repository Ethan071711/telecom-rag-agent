# 5G 网络与 VoNR 高清通话

## 使用 5G 需要满足的条件

1. 手机支持 5G；
2. 办理了支持 5G 的套餐（4G守护卡19元不支持 5G）；
3. 使用 5G SIM 卡，老的 4G 卡如果无法使用 5G，可以到营业厅免费更换；
4. 所在位置有 5G 信号覆盖，可以在 App「网络—覆盖查询」中查看。

## VoNR 高清通话

VoNR 是基于 5G 网络的高清语音通话，通话时不会从 5G 回落到 4G，接通更快，通话时上网也不中断。只需要在手机“设置—移动网络”中打开“VoNR”或“5G 通话”开关即可使用，不额外收费，通话分钟数按套餐正常扣减。

## 5G 耗电与省电

5G 网络耗电相对较高，可以开启手机的“智能 5G”模式，在不需要高速网络时自动切换到 4G。

## 5G 网速说明

5G 实际网速受信号强度、基站负载和手机性能影响。当月套外流量费达到封顶后网速会降至 1Mbps，这时无论是否在 5G 覆盖区都会限速。
